# Multi-Tab & Pop-up Handling Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Enable QA Auto to record and replay user interactions across multiple browser tabs and popups (e.g. `target="_blank"`, `window.open`, OAuth popups) while maintaining 100% backwards compatibility with existing single-page recordings.

**Architecture:** Add `page_id: int | None = None` to `Step`. Expose `context` on `BrowserManager`. Instrument newly spawned pages via `context.on("page", ...)` in `Recorder`. In `ReplayEngine`, route actions and assertions to the target page matching `step.page_id`.

**Tech Stack:** Python 3.13, Playwright async API, Pydantic, Typer.

## Global Constraints

- Python `>=3.13`, Ruff `target-version = "py313"`, line length 100.
- `page_id` is optional on `Step` (default `None`), ensuring 100% backwards-compatibility for existing recordings.
- Offline by default; use local data URIs or in-memory pages for tests.
- Ruff rules: `E, F, I, UP, B, SIM`. Strict typing (`disallow_untyped_defs`).
- Exit codes: `0` on success, `1` on assertion failure, `2` on error.
